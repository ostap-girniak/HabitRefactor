## 🔮 Relapse Interceptor & The Oracle
**Status**: [В ПРОЦЕСІ / IN PROGRESS]  
**Концепт**: Проактивний AI агент, який аналізує ризики і відправляє "жорсткі" Push-повідомлення (Danger Zone) перед можливим зривом.

### 🟢 Що вже реалізовано (Ready Code):
1. **AI Oracle (Оракул)**: Створена логіка (`app/stats/oracle.py`), яка аналізує `checkins`, `sleep_quality`, `stress_level` та генерує `danger_zone: True`, розраховуючи `risk_score` та високу годину ризику.
2. **Фоновий Worker (APScheduler)**: Написаний цикл в `app/workers/scheduler.py`, який щопівгодини сканує юзерів, викликає Oracle і шле Web Push.
3. **Фронтенд Service Worker**: `public/sw.js` готовий приймати пуші у фоні, показувати їх системно з кнопками дій.
4. **Налаштування**: UI для активації пушів створено на сторінці `Settings`. Смарт-нагадування створюється автоматично при дозволі.
5. **Database**: Міграція `007_relapse_interceptor_upgrade.sql` розширила таблиці підписки і нагадувань.

### 🟡 Що ТРЕБА ДОРОБИТИ (Наступні кроки):
- [ ] **VAPID Ключі**: Згенерувати і прописати криптографічні ключі для Push API. (Бекенд: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`; Фронт: `NEXT_PUBLIC_VAPID_PUBLIC_KEY`).
- [ ] **ENV Змінна**: Встановити `ENABLE_RELAPSE_INTERCEPTOR=True` у бекенді для активації воркера.
- [ ] **UI налаштування перехоплювача (Опціонально)**: Створити окрему панель в `Settings` для ручного керування порогом чутливості Oracle (напр. > 70%) та керування щоденними нагадуваннями (ранок/вечір).
- [ ] **Бойове тестування**: Перевірити проходження пуш-повідомлень на реальному смартфоні (PWA) та обхід фонових обмежень ОС.
