# HabitRefactor (Catalyst Forge) — Огляд Проєкту

## 1. Загальна концепція
**HabitRefactor** — це високотехнологічна платформа для трансформації звичок, розроблена на стику поведінкової психології та штучного інтелекту (ШІ). Проєкт виходить за рамки звичайного "трекінгу" і пропонує систему "поведінкової інженерії", фокусуючись на першопричинах звичок: тригерах, оточенні та емоційному стані.

## 2. Технічна архітектура
### Фронтенд (The Forge)
- **Фреймворк**: Next.js 14+ з підтримкою Turbopack.
- **Стилізація**: Vanilla CSS + Tailwind для створення преміальної темної естетики (Glassmorphism).
- **Управління станом**: React Hooks + React Query для синхронізації даних у реальному часі.
- **Інтерактивність**: Спеціально розроблені компоненти, такі як теплова карта (Heatmap) у стилі GitHub та 24-годинна сітка деталізації активності (Drill-down).

### Бекенд (The Engine)
- **Фреймворк**: FastAPI (Python 3.12).
- **Автентифікація**: Supabase Auth (на основі JWT).
- **База даних**: Supabase (PostgreSQL) з політиками безпеки на рівні рядків (RLS).
- **Інтеграція ШІ**: Google Gemini Pro для аналізу настрою та формування рекомендацій щодо запобігання зривам.
- **Логіка часових поясів**: Інтелектуальна нормалізація часу UTC у локальний (зміщення +4г для України/Києва).

## 3. Основні функціональні модулі
### А. Бойова панель (War Room)
- **Теплова карта**: Візуальне представлення стабільності звичок за 365 днів.
- **Погодинна деталізація**: Інтерактивний інтерфейс на 24 квадрати, що дозволяє побачити точну годину успіху або зриву.
- **Динамічна статистика**: Розрахунок зекономлених коштів та повернутого часу на основі метрик звичок у реальному часі.

### Б. Система щоденних чекінів (Daily Check-in)
- **Контекстне логування**: Фіксація не лише результату (Так/Ні), а й настрою (1-10), тригерів, якості сну та оточення.
- **Пріоритет чесності**: Психологічний підхід, де фіксація зриву розцінюється як "цінні дані", а не як поразка.

### В. ШІ-аналітика та База знань
- **Розпізнавання патернів**: ШІ аналізує тижневі дані для пошуку кореляцій між поганим сном/стресом та зривами.
- **Рекомендація ресурсів**: На основі конкретних проблем користувача ШІ пропонує психологічні матеріали (книги, відео, техніки).

## 4. Наукова новизна (для дипломної роботи)
- **Часово-просторова кореляція у формуванні звичок**: Як фіксація оточення та часу допомагає у виявленні зон високого ризику.
- **Гейміфікована зміна ідентичності**: Використання візуального прогресу для переходу користувача від стану "намагаюся кинути" до "стаю новою людиною".
- **Об'єктивізація суб'єктивного досвіду**: Перетворення емоційних станів та відчуттів у структуровані погодинні дані для подальшого аналізу.
